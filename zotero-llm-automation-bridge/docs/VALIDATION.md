## 0.1.6：Zotero 10 与设置面板修复

日期：2026-10-15。真实宿主：Windows Zotero 10.0.6，llm-for-zotero 3.9.11，Ethereal Style 6.0.91。

- Zotero 更新到 10.0.6 后，0.1.5 因清单上限为 `9.0.*` 被宿主禁用。0.1.6 将上限扩展为 `10.0.*`，通过原生更新队列安装并处于 active 状态。
- 设置控制器移入 Bridge 全局对象，避免偏好页脚本作用域导致初始化函数不可见。
- 真实设置页 DOM 已验证：模型下拉框启用，包含默认项和 3 个 API 模型；Prompt 文本框启用并显示原有 15,857 个字符、版本 3。
- 自定义 Prompt 下拉框启用，包含占位项和 llm-for-zotero 的 4 个自定义 Prompt。选择后可显式载入，再保存为 Bridge 独立版本。
- 任务队列改为 8 列表格。真实设置页显示 3 条已有任务，状态、文献、评分、Prompt、模型、尝试次数、更新时间、详情和重试按钮均已渲染。
- 导入只读取 `customShortcuts`，不修改 llm-for-zotero 偏好。模型列表仍只读取现有配置，不复制密钥到 Bridge 状态或日志。
- 42 项 Node.js 测试通过，新增自定义 Prompt 解析、无副作用导入、设置页初始化和控件填充测试。
- 桌面控制工具因当前 WSL 工作目录 URI 无法初始化，因此没有声称完成截图验收；上述控件通过 Zotero 运行时 DOM 读取核对。

## 0.1.5：Markdown 修复与旧笔记迁移

日期：2026-10-07。真实宿主：Windows Zotero 9.0.6，llm-for-zotero 3.9.10，Ethereal Style 6.0.86。

### Markdown 修复与旧笔记迁移

- 已通过 Zotero 原生插件管理器更新并加载 Bridge 0.1.5；安装包与构建包 SHA-256 一致。
- 两份真实旧版子笔记已迁移。任务记录与迁移前一致，没有创建新任务或调用模型。
- 完整测试笔记转换后包含 73 个标题（含总标题）、125 个加粗节点、1 个表格和 75 个原生 math 节点；旧的纯文本 pre-wrap 容器已移除。
- 原始 HTML 在 Zotero 数据目录的 `llm-automation-bridge/markdown-backups/` 中保留。去除 Zotero 数据库外层包装后，备份与迁移前原文逐字一致。
- 迁移保留原笔记、父条目和生成信息；只处理带 Bridge 标记且关联完成任务的旧格式笔记。
- 固定内置 Marked 18.1.0，采用独立实例及受控 renderer。参考官方 [Marked 扩展接口](https://marked.js.org/using_pro)。
