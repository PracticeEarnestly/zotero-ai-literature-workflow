# Zotero LLM Automation Bridge 0.1.7

本版本把从未自动化的现有五星论文纳入分析队列。

## 主要变化

- 启动时扫描当前五星论文。
- 同一论文已有任何 Bridge 任务记录时不重复入队。
- 没有本机任务记录、但已有同步 Bridge 自动笔记时也不重复入队。
- 设置页新增“重新扫描未处理的五星论文”按钮。
- 任务表格用“现有 5”标记补录任务。
- 队列保持严格串行；失败任务仍需手动重试。

## 验证

- 43 项自动化测试通过。
- 真实文库共有 28 篇五星论文：2 篇已有任务、1 篇已有 Bridge 笔记、25 篇成功加入队列。
- 扫描时保持自动化暂停，没有产生模型调用。
